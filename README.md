# Financial Engineering Portfolio

Python projects about finance. I use assets like crypto and stocks.

## Projects

| Project | Description |
|---------|-------------|
| [01-financial-data-analysis](01-financial-data-analysis) | Study past prices of assets: returns, risk, and correlations. Result: EDA project with charts and simple conclusions. |
| [02-portfolio-optimization](02-portfolio-optimization) | Build a portfolio with statistics, correlation, and linear algebra. Result: best portfolio and Efficient Frontier. |

## How to install

You need Python 3.10 or newer.

1. Make a virtual environment:
```bash
python -m venv .venv
```

2. Turn it on:
```bash
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Mac/Linux
```

3. Install the packages:
```bash
pip install -r requirements.txt
```

## How to run

Start Jupyter:
```bash
jupyter notebook
```
